## Animations & Interactions

### Scroll Animations
- All sections use ScrollReveal component
- Content appears/disappears on scroll
- Directional animations (left, right, up)
- Staggered delays for grid items

### Hover Effects
- Card shadows and borders
- Icon color changes
- Image zoom effects
- Button transformations

### Motion Elements
- Stats counter appearance
- Timeline cards fade-in
- CTA button hover states
- Signature fade-in

## Color Palette Used

- **Primary:** Orange/Red (#C44A1A) - Brand color
- **Accent:** Yellow - Secondary highlights
- **Text Dark:** Deep gray/black - Main content
